# Project: AI for Doctors Presentation

## Overview
Reveal.js 5.1.0 presentation for doctors unfamiliar with AI developments.

## File Structure
- `index.html` - Main presentation file
- `nobel_winners.jpg` - Nobel laureates photo from Nature

## Design Constraints
- **Navigation space**: Reserve 80px at bottom for Reveal.js controls
- **Content must not overflow**: All slides must fit within visible area above navigator
- **Theme**: Dark gradient background (professional for medical audience)
- **Fonts**: Inter (body), Space Grotesk (headings)

## Slide Guidelines
- Keep text concise - speaker will elaborate
- Use fragment animations for lists
- Glass card components for structured content
- Images should be sized appropriately (max ~350-380px width for portraits)

## Common Issues
- Slides overflowing navigator: Reduce content, decrease font sizes, or reduce image sizes
- Images not loading: Check file paths are relative to index.html
